# AKK Visoko — nezvanični koncept sajta

Nezavisni demonstracijski prijedlog za porodični obrt AKK Visoko. Nije službeni sajt niti online prodavnica.

Sadržaj o historiji i kategorijama zasnovan je na [razgovoru za Hayat.ba](https://www.hayat.ba/news/article/od-dede-serifa-do-unuka-prica-iz-visokog-koja-traje-60-godina-dokazuje-da-kvalitet-uvijek-opstaje/69e4ab83b1362cc4c6fbe0fe). Naručivanje vodi na javno navedeni Instagram profil. Uslovi prodaje, cijene, dostupnost i kontakt podaci nisu potvrđeni i zato nisu izmišljeni. Ilustracije su originalni SVG koncept, ne fotografije stvarnih proizvoda. Logo je privremeni tipografski natpis.

Otvoriti `index.html` ili poslužiti direktorij statičkim serverom. Nema zavisnosti ni build koraka.
